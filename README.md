# Professional Portfolio Project

Ekti interactive personal portfolio website ja React, Vite, ebong Spline 3D diye toiri kora hoyeche. Ei project-ti modern web technology-gulo use kore ekti dynamic ebong engaging user experience toiri korar jonno banano hoyeche.

## Features (Portfolio Sections)

Ei portfolio-te nicher section-gulo ache, ja homepage theke icon navigation-er maddhome access kora jay:

* **Home:** Ekti stunning 3D Spline scene shoho landing page.
* **Contact:** Contact korar jonno details.
* **Objective:** Career objective statement.
* **Personal Info:** Basic personal details.
* **Education:** Academic background.
* **Skills:** Computer literacy ebong onnano skills.
* **Languages:** Language proficiency.
* **Assessment:** Self-assessment ebong strengths.
* **Experience:** Internship ebong training details.
* **Activities:** Co-curricular activities.
* **Declaration:** Ekti final declaration statement.

## Technology Used

Ei project-ti nicher technology-gulo use kore toiri kora hoyeche:

* **Frontend:** React
* **Build Tool:** Vite
* **Language:** TypeScript
* **3D Design:** Spline (@splinetool/react-spline)
* **UI Components:** shadcn/ui
* **Styling:** Tailwind CSS
* **Routing:** React Router DOM
* **Animation:** GSAP (gsap)

## How to Run Locally

Ei project-ti apnar local machine-e run korar jonno:

1.  **Clone the repository:**
    ```bash
    git clone <https://github.com/shazzad098/spline-sparkle-cv>
    cd <project-directory>
    ```

2.  **Install dependencies:**
    *(Apni `npm` ba `bun` je kono ekti use korte paren)*
    ```bash
    npm install
    ```
    Or
    ```bash
    bun install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  Browser-e `http://localhost:8080` (ba terminal-e dekhano port) open korun.
